# LESSONS

- **8.11.2026.** The cheapest token is the one never sent: lean CLAUDE.md, skills for the rest, quiet commands.
- **8.11.2026.** Choose the model for a child *before* it starts; changing it mid-session breaks the cache.
- **8.11.2026.** A subagent is not free (own tokens, own five-minute cache); it pays off when it digs a lot and returns a
  paragraph, or when it runs while the master does something else.
- **8.11.2026.** Two children in one application or repository break each other; split by application.
- Not yet proven in a full run; the first one adds its lessons here.
